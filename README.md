# ProjetoAceitacao-GQS

This is an academic project developed for the Software Quality Assurance class, focusing on **Acceptance Functional Test Automation** for a web application.

## Technologies

The automation project uses the following key technologies:

* **Language:** Java 8+

*

**BDD Framework:** Cucumber (Gherkin)

* **Web Automation:** Selenium WebDriver (Assumed)

* **Dependency Manager:** Maven
